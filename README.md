# 淨稿台

把文案貼進去就乾淨 —— 自動清掉會讓格式跑掉的隱形字元，輸出成 AI 讀得懂排版的 Markdown 檔案。

單一 HTML 檔，沒有相依套件，沒有建置步驟。雙擊 `index.html` 即可使用，
或丟到任何靜態主機。

## 解決什麼問題

從備忘錄、Word、LINE、FB、Google 文件複製的文案，會夾帶一堆看不見的字元。
它們在畫面上長得跟空格一樣，但會讓搜尋對不上、JSON 解析失準、段落在別的
系統裡整個黏成一行。

貼上的當下就攔掉這八種（無條件清除）：

| 字元 | 為什麼非清不可 |
| --- | --- |
| 零寬字元 / BOM | 完全看不見，讓搜尋、比對、JSON 解析失準 |
| 不換行空格 NBSP | 蘋果與 Word 最常偷塞，長得像空格但不是 |
| 排版用細空格 | 從網頁或 PDF 複製時夾帶的各種寬度空格 |
| 行分隔符 U+2028 / U+2029 | 備忘錄與 Pages 的換行，很多系統讀不出來 |
| Windows 換行 CRLF | 行尾多一個看不見的 CR，字串比對永遠對不上 |
| 定位字元 Tab | 貼進欄位會變成喬不好的縮排 |
| 軟連字號 | 隱形的斷字符號，複製到別處會冒出一個 `-` |
| 控制字元 | 從 PDF 或郵件複製時夾帶的不可見控制碼 |

另有四項風格選項由使用者自己決定：彎引號轉直引號、清除行尾空白、
連續空行壓成一行、全形空格轉半形（預設關，中文排版常是刻意的）。

## 輸出格式

YAML 檔頭 + Markdown 正文。AI 先讀檔頭知道這是什麼，再讀正文拿到排版；
人用任何裝置打開都是同一份純文字。

```markdown
---
標題: "世貿101興康華廈 電梯三房"
類型: "物件文案"
標籤: ["信義區", "三房", "3098萬"]
摘要: "象山站步行 4 分鐘的電梯三房，開價 3098 萬"
日期: 2026-10-07
字數: 218
格式: "Markdown / UTF-8 / LF"
---

# 世貿101興康華廈 電梯三房
...
```

檔名為 `YYYY-MM-DD_標題.md`，日期在前，雲端硬碟才會照時間排序。
輸出一律 UTF-8 無 BOM、LF 換行、結尾正好一個換行。

## 一鍵直接存進雲端硬碟

把瀏覽器的下載位置設成雲端硬碟的同步資料夾，並關掉「下載前詢問每個檔案的
儲存位置」，按一下檔案就在雲端了。

- Chrome：設定 → 下載 → 位置
- Safari：設定 → 一般 → 檔案下載位置

## 實作備註

淨稿規則的正規表示式一律用 `String.fromCharCode()` 組出來，**不寫 `\uXXXX`
字面轉義**。這份檔案在傳輸、複製、存檔的過程中，轉義有可能被還原成真字元
（正是本工具要解決的那個問題），那會讓整組規則當場失效 —— 開發時就踩過
一次，整個原始碼被塞進 12 個隱形字元。
